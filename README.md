# 选品拓品分析 · 跨行业通用方案

> 一套行业无关的方法论框架，用于产出**节点性选品拓品榜单**。
> 输入：第三方消费榜（友望/蝉妈妈等）+ 内部投放数据（adata等）
> 输出：市场缺口识别 + 赛道机会评级 + 三级商品下钻 + 双版 HTML 报告

## 核心方法论

```
消费端需求（平台A × 平台B） → 我方供给（内部投放） → 历史季节验证
         ↓                          ↓                      ↓
   四类需求来源标签          重/中/轻供给 + 动量      去年排名 + 商品基础
         ↓                          ↓                      ↓
         └──────────────────────────┼──────────────────────┘
                                    ↓
            四类最终结论：市场缺口 / 已布局 / 市场饱和 / 观察验证
```

### 关键设计决策

| 旧做法（已撤回） | 新做法 |
|---|---|
| 固定 10% 判热门/缺口 | 平台内 30%—40%—30% 相对排名 |
| 固定 12%/6% 区分重投/轻投 | 近 4 周内部 GMV 排名分层 |
| 「平台 B 强 = 平台 A 红海」 | 平台 B 外部验证 = 待迁移机会 |
| 单凭我方投放规模高 = 饱和 | 需需求+供给+效率三类证据齐全 |
| 外部占比与内部占比直接相减 | 跨口径只做差集+同源趋势 |

## 快速开始

### 美护行业（直接使用）

在新会话中粘贴 `新会话启动Prompt_美护选品拓品最终分析.md` 的全部内容即可。Agent 会自动读取项目记忆和分析框架，产出最终榜单。

### 新行业接入（需先行业建模）

1. 确认行业范围（纳入/排除哪些一级行业）
2. 建立赛道桶字典 `references/buckets_{行业}_v1.json`（8—15 桶）
3. 建立三类数据的归桶映射（平台 A 关键词 / 平台 B 类目路径 / 内部路径语义）
4. 验收匹配率（各源未匹配 < 30%）
5. 确认历史数据窗口
6. 进入标准三层分析链
7. 产出最终 MD 草稿 → 用户确认 → 双版 HTML

详细步骤见 `SKILL_xuanpin_tuopin_cross_industry.md` §七。
