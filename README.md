Skill 名称：cross-platform-category-opportunity-benchmark

解决问题：

拍脑袋定"赛道热不热 / 缺口大不大" → 给出非主观相对排名 Benchmark
单一平台信号失真（视频号 vs 抖音消费者偏好不一致）→ 强制要求双平台交叉验证
我方供给 vs 外部市场需求脱节 → 把需求与供给拉到同一张图
三层判断链：

市场需求层：视频号 × 抖音双平台规模 + 同比 + 4 周稳定性 → 平台内 30%-40%-30% 相对排名
我方供给层：GMV / 消耗排名 + 周动量 + SPU 主体宽度 + ROI + 集中度 → 1-3 重 / 4-7 中 / 8-10 轻供给
历史季节层：去年 6-8 月同期商品与客户结构 → 验证夏季趋势稳定性
四类结论：

结论	触发条件
🟢 市场缺口	需求扩张 + 供给轻量 + 历史有迹
🔵 已布局	需求稳定 + 供给足量 + 持续投放
🟡 观察验证	信号矛盾或窗口不全
⚪ 市场饱和	需求收缩 + 供给过载 + ROI 走弱
关键反直觉：

❌ 抖音强 / 视频号弱 ≠ 红海或非重点
❌ 固定 10% 阈值 ≠ "赛道热"
❌ 早期 SPU 数少 ≠ 供给弱
✅ 缺口的判定必须满足"需求扩张 + 供给轻量 + 历史有迹"三者交叉
